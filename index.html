Author of Codes

The GPUPEGAS code for galaxy simulations demonstrated a 55-fold speed-up on a single GPU accelerator and a parallel efficiency of 96% when scaled to 60 GPUs (Kulikov, ApJS, 2014)

The AstroPhi code for hydrodynamics simulations demonstrated a 27-fold speed-up on a single Intel Xeon Phi accelerator and a parallel efficiency of 94% when scaled to 32 accelerators (Kulikov et al., CPC, 2015)

The AstroPhi 2.0 AVX-512 code for hydrodynamic simulations demonstrated a performance of 173 GFLOPS with a 48-fold speedup on a single Intel Xeon Phi processor, while exhibiting a 97% weak scalability when scaled to 16 Intel Xeon Phi 7290 processors (Kulikov et al., ApJS, 2019)

The RHydroBox3D code for simulating special relativistic hydrodynamic flows demonstrated a 94% parallel efficiency when scaled to 768 cores on the Intel Xeon X5670-based NKS-30T cluster (Kulikov, CPC, 2020)

The RHydroBox3D 2.0 Coarray Fortran code for special relativistic hydrodynamics demonstrated is 92% on a cluster with Intel Xeon 6248R NKS-1P with 192 Coarray Fortran images (Kulikov et al., Mathematics, 2022)

The ngFEOSAD code is designed for the numerical modeling of star formation, integrating Coarray Fortran with CUDA Fortran and OpenMP (McKevitt et al., JPDC, 2025)
